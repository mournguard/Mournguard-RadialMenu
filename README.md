# Mournguard-RadialMenu
Simple Radial Menu easily build via nested `Array`s of `RadialMenuOption` a (String,Callable) Tuple.

# Requires
- [![Mournguard-Utils](https://img.shields.io/badge/Mournguard-Utils-blue?logo=github)](https://github.com/mournguard/Mournguard-Utils)
	- `git submodule add -- git@github.com:mournguard/Mournguard-Utils.git .\addons\Mournguard-Utils`
